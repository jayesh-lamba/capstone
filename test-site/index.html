This host page is served from http://localhost:5500 to simulate an external customer website embedding the FlyRank lead-capture widget from http://localhost:3000.

Cross-Origin Verification Details:

  • Widget Script: http://localhost:3000/widget.v1.js?id=e7b4010a-3d96-48c9-94b2-03d6d03d32cb
  • Configuration API: http://localhost:3000/api/v1/widgets/e7b4010a-3d96-48c9-94b2-03d6d03d32cb/config
  • Submission API: http://localhost:3000/api/v1/submissions

How This Works

  1. The host page loads the embed script tag below with defer.
  2. The script extracts id=e7b4010a-3d96-48c9-94b2-03d6d03d32cb and queries the public config endpoint via CORS.
  3. The widget mounts an isolated Shadow DOM container at the bottom-right of this page.
  4. When a visitor submits the form, the browser issues a CORS preflight OPTIONS request followed by a cross-origin POST.
  5. The backend records the submission under the owning tenant with IP geolocation and delivers a 201 Created response.
